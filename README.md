## 遇到的问题与解决过程

本节将以对话+练习的形式记录关键问题与解决方式，便于回溯与复用。对应代码主要在 `example/collection101/main.go`。

### 1. 命名与导出：为什么 `uniqueStrings` 不是大写 `U`？

- 问题：为何不用 `UniqueStrings`？
- 结论：Go 的导出规则是首字母大写才导出（跨包可见）。当前函数只在 `package main` 中使用，用小写更合适；若迁入工具包对外提供，则改为大写。

### 2. 去重实现：`uniqueStrings` 应如何优化？

- 初版（粗糙）：每次向结果追加前线性扫描结果切片判断是否已存在，时间复杂度 O(n^2)。
- 优化思路：使用 `map[string]struct{}` 作为“已见集合 seen”，一次遍历完成去重，时间复杂度降为 O(n)，空间 O(n)。
- 关键点：
  - `seen[s] = struct{}{}` 仅表示“存在”，空结构体零占用；
  - 顺序保持为首次出现顺序；
  - 变量名 `seen` 表示“已经见过的集合”。

示例（优化版伪码）：

```
out := make([]string, 0, len(xs))
seen := make(map[string]struct{}, len(xs))
for _, s := range xs {
    if _, ok := seen[s]; ok { continue }
    seen[s] = struct{}{}
    out = append(out, s)
}
```

### 3. 交集函数：`intersectInts` 到底做什么？

- 目标：返回两个整型切片的交集，且结果不包含重复项。
- 例子：`[1,2,3,3,4]` 与 `[3,4,4,5]` 的交集是 `[3,4]`。
- 粗糙版：双重循环匹配并在加入结果前线性去重，简单易懂但最坏 O(n*m + k^2)。
- 优化版：将较短切片放入 `set`，再遍历另一边，并用 `added` 去重，复杂度 O(n+m)。

### 4. 切片分块：`chunkSlice` 是否需要拷贝？

- 粗糙版：直接返回原切片的子切片（不拷贝），代码短，但子切片与原切片共享底层数组，可能导致后续修改互相影响。
- 改进（已采用）：在返回前 `copy` 一份，消除共享带来的副作用，更安全，可读性更好，代价是多一份内存与拷贝。

最小示例：共享与拷贝的差异

```go
xs := []int{1,2,3,4}
// 视图：共享底层数组
view := xs[0:2]   // view -> [1 2] 共享 xs
view[0] = 100     // 修改 view 影响 xs：xs 变为 [100 2 3 4]

// 拷贝：独立内存
buf := make([]int, len(view))
copy(buf, view)   // buf -> [100 2] 与 xs 无关
buf[0] = 7        // 修改 buf 不影响 xs
```

在 `example/collection101/main.go:chunkSlice` 中，当前实现为“安全版”（拷贝每个分块）。

### 5. 安全访问：`safeGet` 的返回约定

- 约定：越界返回类型零值与 `false`；合法返回元素与 `true`。
- 价值：调用方无需 `recover` 或额外判断，接口语义清晰。

## 今日学习要点（复习清单）

- 导出规则与命名：
  - 首字母大写为导出（跨包可见），小写为包内使用。
  - 如需对外使用，函数命名为 `UniqueStrings`；当前 `package main` 内使用用小写即可。

- 去重思路（uniqueStrings）：
  - 粗糙版：结果切片线性查重，O(n^2)。
  - 优化版：`seen := map[string]struct{}` 判重，O(n)；保持首次出现顺序。
  - 语义细节：输入为 `nil` 返回 `nil`，空切片返回空切片（已实现）。

- 交集函数（intersectInts）：
  - 功能：返回 a 与 b 的去重交集；结果顺序不作保证。
  - 优化版：较短切片进集合，遍历另一边，O(n+m)；用 `added` 去重。
  - 空输入约定：任一为空时返回空切片；若两者均为 `nil`，返回 `nil`（已实现）。

- 分块（chunkSlice）：
  - 差异：视图 vs 拷贝。`xs[i:end]` 是共享底层数组的视图；修改可能影响原切片。
  - 安全版：对每个块 `copy` 出独立切片，避免副作用（已实现）。
  - 示例已补充到 README，理解共享底层数组的风险。

- 安全访问（safeGet）：
  - 约定：越界返回零值与 `false`；合法返回元素与 `true`。

- 泛型速记：
  - `func chunkSlice[T any](xs []T, size int) [][]T` 中 `[T any]` 表示类型参数 T 可为任意类型。
  - 可扩展为 `T comparable` 等约束实现泛型去重。

- 表驱动测试：
  - 结构：定义用例切片 + `t.Run` 子测试 + 明确断言。
  - 路径：`example/collection101/main_test.go` 覆盖四个函数的常见与边界场景。
  - 运行：`go test -v ./example/collection101`，或 `go test ./...`。

- 覆盖率：
  - 命令：`go test -coverprofile=cov.out ./example/collection101`，`go tool cover -func=cov.out`/`-html=cov.out`。
  - 作用：发现未执行的代码块；不能代表测试充分性，仍需设计好断言与场景。
